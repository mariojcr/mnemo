Running in three steps

Deploy

One container and ClickHouse. Point it at your OIDC provider and a model server.

Connect

Run mnemo login in Claude Code, or add it as a connector in Claude.ai or Grok.

Work as usual

mnemo distills each session into memories in the background and brings back the relevant ones.

Six answers per memory

Each memory records what happened, who was involved, when, where, why and how, with the conversation it came from.

Versions instead of overwrites

When something changes, the old memory is marked as replaced and stays in the history.

Private by design

Every person sees only their own memory. Admins see counts, not content; with SSO there is no way around it, and with keys every key says who minted it.

Your models, your data

Distillation and embeddings run on your own GPUs through any OpenAI-compatible server.
